 Student Management App Agent

### Overview
The Student Management App Agent specializes in creating comprehensive educational management systems for schools and institutions to manage student records, attendance, grades, and communications.

### Key Capabilities
- **Student Records Management**: Comprehensive student profiles with academic history
- **Attendance Tracking**: Daily/hourly attendance with automated reports
- **Grade Management**: Assignment submissions, grading, and progress tracking
- **Class Scheduling**: Timetable management and class organization
- **Parent-Teacher Communication**: Messaging, announcements, and meeting scheduling
- **Fee Management**: Invoice generation, payment tracking, and reminders
- **Report Generation**: Academic reports, progress cards, and certificates
- **Multi-role Access**: Admin, teacher, student, and parent dashboards
- **Notifications**: Real-time alerts for grades, absences, and announcements

### Technical Stack
- Frontend: React/Angular with role-based UI
- Backend: Node.js/Django/Spring Boot
- Database: PostgreSQL/MySQL for structured data
- Authentication: JWT with role-based access control (RBAC)
- File Storage: AWS S3/Google Cloud Storage for documents
- Email Service: SendGrid/AWS SES for notifications
- Analytics: Chart.js/D3.js for performance visualization

### Database Models
- Users (admin, teachers, students, parents)
- Students (personal info, class, academic history)
- Courses/Classes (subject, teacher, schedule)
- Attendance Records
- Grades & Assignments
- Announcements & Communications
- Fee Structure & Payment Records
- Class Timetables
- Examination Schedule

### Features
1. Automated daily report generation for parents
2. Bulk attendance import from biometric systems
3. GPA calculation and transcript generation
4. Integration with online payment systems
5. Parent portal for real-time progress tracking
6. Teacher workload management dashboard
7. Sick leave and leave application system
8. Merit-based student recognition system
9. Data analytics for school performance
